# 10漫画—重制版

用于腾讯动漫、哔哩哔哩等多个网站漫画分章节下载，支持自定义规则导入。

> 本项目是基于 [journey3510/10Comic](https://github.com/journey3510/10Comic) 的重制/派生版本。请保留来源链接与致谢；对上游代码、规则或其他受版权保护内容的使用，仍须遵守其适用的授权条件。

## 亮点

- 液体玻璃风格的重制界面，集中管理章节、任务、搜索与规则。
- 按章节建立下载任务，支持队列、进度、暂停/取消、失败诊断与记录管理。
- 支持内置规则、可视化自定义规则、导入/导出备份与复杂站点的隐藏 iframe 解析。
- 面向腾讯漫画、哔哩哔哩漫画等多个站点的规则化适配。

## 文档

- [详细功能说明](./docs/功能说明.md)：界面、下载、搜索、规则、设置与故障排查。

## 安装

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或兼容的用户脚本管理器。
2. 打开仓库中的 [`10漫画—重制版.user.js`](./10漫画—重制版.user.js)。
3. 选择“Raw/原始文件”，再由脚本管理器确认安装。
4. 在支持的漫画站点登录后打开作品或章节页，按脚本界面提示操作；需要时从设置中导入规则。
