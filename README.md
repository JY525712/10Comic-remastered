# 10漫画—重制版

用于腾讯动漫、哔哩哔哩等多个网站漫画分章节下载，支持自定义规则导入。

> 本项目基于 [journey3510/10Comic](https://github.com/journey3510/10Comic) 进行重制与扩展；请保留该来源标注。原项目仓库未在本次发布核查中发现根目录 `LICENSE` 文件，因此此处仅作来源致谢，不对原项目的授权范围作额外声明。

## 亮点

- 液体玻璃风格的重制界面，集中管理下载、搜索与规则。
- 按章节下载漫画内容，支持批量任务与进度管理。
- 支持导入、导出和自定义站点规则，便于在站点页面变动后维护。
- 面向腾讯动漫、哔哩哔哩等多个站点的规则化处理能力。

## 安装

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或兼容的用户脚本管理器。
2. 打开仓库中的 [`10漫画—重制版.user.js`](./10漫画—重制版.user.js)。
3. 选择“Raw/原始文件”，再由脚本管理器确认安装。
4. 在支持的漫画站点登录后打开作品或章节页，按脚本界面提示操作；需要时从设置中导入规则。

哔哩哔哩模块只适用于**免费章节**，以及当前登录账号已经购买、订阅或以其他方式获得合法访问权限的章节。

## 规则使用提示

- 先在单个已授权章节验证规则，再进行批量操作。
- 规则应只描述公开页面或你当前账号有权访问的内容；不要添加任何规避访问限制的逻辑。
- 若站点改版，请先检查页面实际结构，再更新规则。欢迎在不含敏感数据的前提下提交兼容性反馈。
