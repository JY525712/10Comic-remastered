# 2.0.12 优化说明

本版以用户提供的 2.0.11 为基线。所有修改在独立分支 `codex/optimize-2.0.12` 上完成，原下载文件及原有 `sfacg-adapter` 工作目录保持完整。

最终安装文件为 **422,771 字节**，比原版减少 **29.64%**。本机 3000 章节、7 次勾选的耗时中位数从 **15.8 ms** 降至 **3.7 ms**，新增行节点从 21,000 个降为 0；这是离线夹具下的对比，不代表所有网站的实际耗时。完整测试 **47/47**，视口、主题和减弱动态效果检查 **27/27**。文件哈希见 [验证记录](./验证记录.json)，审查情况见 [复核记录](./复核记录.md)。

| 可访问性 | 模态层维护焦点栈、Tab 循环、Escape 关闭和触发点恢复；隐藏层退出键盘导航 | 原有确认操作、诊断、规则说明、下载选项抽屉与快捷键 |

| 运行开销 | 移除当前输出流程未调用的 ZIP vendor 及对应运行时辅助代码；无匹配站点时延迟配置初始化；隐藏时暂停装饰动画 | STORE ZIP 流式输出、任意站点添加规则菜单、后台下载与恢复功能 |

## 可编辑源码

`src/userscript/modules/ui.js` 负责状态、初始化和功能协调。`src/userscript/ui/` 包含：

- `styles.css`：可直接编辑的样式，保留主题差异和必要的网页选取光标规则。
- `shell.js`：四主入口、设置和弹窗的壳模板。
- `sites.js`、`chapters.js`、`tasks.js`、`rules.js`：相应业务界面的交互。
- `accessibility.js`：模态焦点与键盘管理。

`scripts/compose-ui.cjs` 在构建时把片段插入原有 UI 作用域。不会增加浏览器运行时依赖或额外网络加载。`format:ui` 会在写入格式化结果前核对执行语义；入口文件的插槽位置不交给通用格式化器移动。

组件样式使用 `:where(#ten-comic-root)` 限定作用域，保持原选择器优先级；原有主题选择器保持原样。六主题回归测试直接与原版比较卡片背景和文字颜色，避免基础样式覆盖浅色主题。

## 兼容性证据

`tests/compatibility.test.cjs` 对原版与优化产物进行 AST 比较，确认站点适配模块、下载工具、下载队列与配置模块的可执行语法保持一致；同时核对用户脚本身份、权限、匹配规则及四个阅读页 worker。

浏览器测试通过真实 DOM 和受控的 GM/目录接口执行操作，验证三种下载输出、图片范围与序号、暂停/继续/取消、任务恢复、旧设置备份导入/导出、搜索、自定义规则模板/可视化选取/测试/保存。

原图输出逐文件核对名称、顺序和字节；ZIP 解包后核对条目名称、顺序和图片字节，避免把打包时间戳当作内容差异；拼接 JPEG 核对文件名称和字节。

存储键、备份格式和目录授权实现未迁移。配置内部版本继续使用原来的 `2.0.8`，避免无必要地触发数据迁移；用户脚本发行版本为 `2.0.12`。

## 验证范围

- 原有 25 项测试全部保留；新增真实 Chromium 交互、下载输出及语法兼容测试。
- 视口：1280×900、640×400、390×844、320×568、844×390；四个主页面以 125% 缩放检查边界、内容高度和横向溢出。
- 六套主题各生成设置页截图；检查系统减弱动态效果。
- 3000 章节、7 次勾选的本机对比报告位于 `dist/verification/chapter-benchmark.json`，记录每次耗时与新增 DOM 节点数。
- 最终命令结果、文件大小和哈希汇总在 `dist/verification/release-report.json`。

测试使用离线网页及可控图片，不依赖真实账号或站点的即时可用性。站点与下载核心保留原版实现；本次未改变同站多标签任务快照的合并语义，也未扩展取消操作在已经提交文件写入后的行为。

## 使用与回退

在用户脚本管理器中安装根目录的 `10漫画—重制版.user.js`，检查版本为 2.0.12。原有脚本名称与 namespace 保持一致，旧设置可继续读取。

需要回退时，重新导入 `baseline/original-2.0.11.user.js`。优化版没有进行数据结构迁移。

源码重新构建：`npm ci`、`npx playwright install chromium`、`npm run build`。验证命令见 README。
