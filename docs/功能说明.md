# 详细功能说明

本说明以当前 `10漫画—重制版.user.js` 的实现为准。页面结构、站点规则和阅读器行为可能随时变化；“内置”表示脚本包含对应规则，不代表目标站点永久可用。

## 使用前准备

1. 安装 Tampermonkey 或兼容的用户脚本管理器，并导入本仓库的 `.user.js` 文件。
2. 在目标漫画的目录页或章节页使用脚本；首次使用时，先确认脚本识别出的站点名与漫画名正确。
3. 先在一个你有权访问的章节中小范围验证，再建立批量任务。

## 设置分组

- “主题”包含预设选择、外观调整和界面设置，点击标题展开或收起；新开页面时默认收起。
- 六款主题预设：极光流银、晨雾晶璃、云白浮雕、黑曜鎏金、霓虹炭黑、深空钛蓝。旧“深海流光”“澄光琉璃”“晴白庭院”设置分别迁移为极光流银、黑曜鎏金、深空钛蓝；外观独立设置保留。
- 下载方式与搜索站点菜单的选中、悬停和指示标记随当前主题切换。三款新主题提供悬停高光、按压反馈和扫光；关闭特效、选择克制动效或启用系统减少动态效果时停用新增位移与扫光。
- 最小化入口分别提供极光流银的银蓝流光环、云白浮雕的呼吸光、黑曜鎏金的金色彗光、霓虹炭黑的蓝粉双弧和深空钛蓝的扫描光；晨雾晶璃保持原样。轻量特效降低动画速度和强度，关闭特效、克制动效及系统减少动态效果时停止新增动画；入口隐藏或页面切到后台时暂停播放。
- “下载”配置区点击标题可展开或收起，新开页面时默认展开。
- “自定义规则”同样默认收起；从站点列表编辑规则或通过脚本菜单为当前网站添加规则时会自动展开编辑器。

## 主界面与章节

- 脚本以独立浮层提供章节、任务、搜索、站点和设置等入口，可在页面内显示或隐藏。
- 在目录页读取章节列表，显示识别到的站点、漫画名和章节数量；站点为 SPA 或动态加载页面时可重新加载章节列表。
- 支持单选、多选、区间选择与全选/取消全选，再将所选章节加入下载任务。
- 加入任务前检查本页正在下载、等待中及保留记录中已完成的同一章节，提供“跳过重复”和“仍然下载”；不同输出方式、图片范围与失败图片补下载分别判断。已完成记录不代表磁盘文件仍存在。
- 支持编辑章节名称、调整章节信息，并可从当前阅读页尝试建立当前章节任务。
- 若页面提示“未匹配”或“网站规则可能已经失效”，说明当前页面结构未被规则识别；请勿用规避站点访问限制的方式解决。

## 下载任务与记录

- 下载页按任务状态管理等待、下载中、暂停、已完成、失败或部分失败的章节。
- 进度按已处理图片计算，另外显示成功取图、失败与已保存页数；ZIP/拼图取图完成后仍会显示打包或生成阶段，保存完成后才更新已保存页数。
- 原图、ZIP 与拼图共用图片响应校验，检查空文件、常见图片文件头及误返回的登录页/错误页；快速直存也会先校验响应内容，再交给浏览器保存。文件头校验不等于完整图片解码或磁盘完整性校验。
- 可配置并发章节数量、每章节图片上限、图片下载范围、图片序号补零规则和下载记录上限。
- “自动清理文件夹和文件名”只修改保存路径：修正系统禁用字符、浏览器不接受的隐藏字符、前导句点和保留名称；必要时将半角 `~` 转为全角 `～`，例如“第29话 拜托啦~”保存为“第29话 拜托啦～”。合法名称中间的 `~` 及 `+ & # % [] ()` 等正常符号保留。关闭后保留原名，浏览器仍可能拒绝不兼容名称。
- 支持压缩下载及浏览器下载路径；当浏览器不授予目录保存权限时，脚本会回退为浏览器默认下载目录。
- 压缩下载需要先选择保存目录。ZIP 会以单文件流式写入，避免长章节在内存中生成完整压缩包；未授予目录权限时会提示改用原图下载或重新选择目录。
- 任务可暂停、继续、取消、移出等待队列；未完成任务可在脚本支持的场景下恢复。
- 恢复记录按页面会话独立保存。在支持 Web Locks 的同源页面中，通过领取互斥避免恢复仍在运行的标签页；不支持时使用会话租约回退。旧恢复记录可继续读取。安装更新时新增的 `GM_listValues` 授权用于查找各会话的恢复记录。
- 取消会停止阅读页加载和解析等待，并清理本次创建的 iframe；需要多批复用的阅读页会保留到其任务清理阶段。
- 记录存储失败时会提示并尽量在当前页面保留历史，后续下载继续；仅在内存中的记录关闭页面后可能丢失。
- 对失败或超时图片提供诊断与补下载入口；下载记录可筛选、删除，并保留失败状态提示。
- 超时、短时网络故障及部分临时 HTTP 错误最多自动重试两次；登录/权限错误、404 和无效图片停止自动重试。限流或服务暂不可用时优先遵循 `Retry-After`，并让本页队列中的同来源请求共同等待；等待期间仍可暂停或取消。服务器要求等待超过十分钟时会提示稍后手动重试，不会提前发送请求。
- 可开启完成通知。刷新目标网页、关闭页面或站点改版都可能中断任务。

## 搜索与站点入口

- 可在具备搜索模板的内置站点中按漫画名称检索，并从结果跳转到目标漫画页。
- 没有搜索模板的内置站点仍可从站点列表直接打开主页。
- 搜索结果和站点可用性由目标站点实时页面决定，脚本不承诺每个站点、每次搜索均可用。

## 自定义规则与备份

- 可查看内置规则，新增、编辑或删除导入规则；可将设置和自定义规则导出为备份，或从备份恢复。
- 简单规则可填写站点名称、域名、主页、漫画标题选择器、章节选择器和图片选择器。
- 对动态阅读器可选用隐藏 iframe、翻页阅读或复杂图片解析函数；复杂规则应仅用于你有权访问的页面。
- 导入的规则可能包含可执行的图片解析函数。只导入自己编写或可信来源、已审阅的规则；不要导入来源不明的 JSON/脚本，也不要在规则中保存 Cookie、Token、密码或其他敏感信息。
- 规则变更后通常需要刷新目标页面，使脚本重新根据规则启用入口。

## 通用自定义站点导入规则

下面的模板适用于常见的“作品目录页包含章节链接、阅读页包含普通 `<img>`”站点。它是填写示例，不能不加修改地直接用于真实网站；请先用浏览器开发者工具确认目标页面的选择器。

```js
[
  {
    domain: ["example.com", "www.example.com"],
    homepage: "https://example.com/",
    webName: "示例漫画站",
    webDesc: "普通卷轴阅读站点",
    comicNameCss: "h1.comic-title",
    chapterCss: ".chapter-list",
    imageCss: ".reader img",
    readtype: 1,
    useFrame: false,
    simpleRule: true,
    getImgs: function (context, processData) {
      const frame = processData && processData.frameId
        ? document.getElementById(processData.frameId)
        : null;
      const root = frame && frame.contentDocument
        ? frame.contentDocument
        : new DOMParser().parseFromString(String(context || ""), "text/html");
      const base = processData && processData.url
        ? processData.url
        : location.href;
      const urls = Array.from(root.querySelectorAll(this.imageCss))
        .map((img) => {
          const srcset = img.getAttribute("srcset") || img.getAttribute("data-srcset") || "";
          return img.getAttribute("data-src")
            || img.getAttribute("data-original")
            || img.getAttribute("data-url")
            || img.getAttribute("data-lazy-src")
            || img.currentSrc
            || (srcset.trim().split(/\s*,\s*/).pop() || "").trim().split(/\s+/)[0]
            || img.getAttribute("src");
        })
        .filter(Boolean)
        .map((url) => {
          try {
            return new URL(url, base).href;
          } catch (error) {
            return url;
          }
        });
      if (frame) frame.remove();
      return [...new Set(urls)];
    }
  }
]
```

字段含义：

- `domain`：匹配域名，可填写字符串或域名数组，不要填写章节路径。
- `homepage`：站点主页，用于站点列表跳转和相对地址补全。
- `webName`、`webDesc`：脚本中显示的站点名称与使用提示。
- `comicNameCss`：作品页漫画标题的 CSS 选择器。
- `chapterCss`：包含章节链接的容器 CSS 选择器。
- `imageCss`：阅读页漫画图片的 CSS 选择器。
- `readtype`：`1` 表示卷轴/单页加载，`0` 表示需要逐页请求的翻页阅读。
- `useFrame`：同源动态阅读页可设为 `true`；跨域页面受浏览器同源策略限制，不能仅靠此开关访问。
- `getImgs`：图片解析函数。导入时函数会作为代码保存和执行，只能使用自己编写或已经逐行审阅的可信内容。

`readerTabMode` 是为 HipMH 等特殊内置适配器保留的能力，不属于通用导入规则的兼容承诺。普通自定义规则不应填写该字段。

## KakaoPage 使用说明

1. 登录 KakaoPage，并打开漫画作品页 `https://page.kakao.com/content/<作品ID>/`。
2. 加载章节列表后，只选择页面明确标记为免费，或当前账号已经购买、租阅、等待免费解锁或以其他合法方式获得访问权限的章节。
3. 开始下载后，脚本会打开并复用一个 KakaoPage 阅读标签页。目标站点正常加载阅读器后，脚本读取浏览器已经收到的 `imageDownloadData.files` 图片地址，再交给现有下载队列。
4. 视频、小说及标记为“网页不可观看”的条目不会加入漫画章节列表。
5. 未登录、尚未购买、尚未解锁或因地区/年龄限制无法正常打开的章节不会触发购买；该章节会在超时后失败并保留错误提示。

KakaoPage 页面可能只渲染当前已加载的章节，脚本不会调用隐藏目录接口来扩展列表。需要更多章节时，请先使用网站自身的列表控件加载它们，再点击脚本中的“重新加载章节”。


## RidiBooks 使用说明

1. 在 RidiBooks 中正常登录并打开作品详情页，例如 `https://ridibooks.com/books/<作品ID>`。
2. 加载章节列表后，选择页面明确标记为免费，或当前账号已经购买、租阅、等待免费解锁或以其他合法方式获得访问权限的章节。
3. 脚本会打开一个 RidiBooks 阅读标签页，等待网站正常返回 `generate` 响应，再从其中的 `data.pages` 读取浏览器已经获得的图片地址。
4. 年龄限制章节会标记为不可选；如果阅读器未返回图片数据，任务会失败并保留错误提示。

RidiBooks 不会自动登录、输入 Cookie、购买、充值、年龄验证、解锁章节或绕过 DRM。对于未授权、地区受限、年龄受限或无法在网页端正常阅读的章节，脚本不会尝试规避限制。

## 拷贝漫画使用说明

1. 打开拷贝漫画的漫画详情页 `https://www.mangacopy.com/comic/<作品标识>`，在脚本中加载章节列表。
2. 阅读页会随正常滚动逐步加载图片。脚本使用离屏同源阅读页触发这一既有加载行为，待图片列表稳定后再下载。
3. 仅处理页面已经正常显示、且具有 `data-src` 的漫画图片；加载占位图不会加入下载任务。
4. 不调用私有接口、不解密图片、不伪造客户端请求，也不会处理网站未正常开放阅读的内容。


## SF 菠萝包漫画使用说明

1. 打开作品页 `https://manhua.sfacg.com/mh/<作品标识>/`，在脚本中加载章节列表。阅读页也可以加载目录。
2. 列表按各分组从旧到新排列，保留 VIP 章节的付费标记，章节名称不包含网站的 VIP 标签。
3. 选择章节后，可使用现有的逐图下载、ZIP 或图片拼接功能。下载时脚本会加载同源隐藏阅读页，等待网站正常生成完整的 `picAy` 图片数组，再按阅读顺序保存。
4. 在章节页使用“下载当前章节”时，填写章节名称即可；作品名称会从阅读页导航中识别。
5. 需要付费或登录的章节，请先在网站正常登录并确认当前账号可以阅读。阅读页跳转、网站返回错误或图片加载超时会使任务失败，并在下载诊断中显示原因。

本适配仅匹配 `manhua.sfacg.com` 漫画站。相对图片路径会补全为 `https://coldpic.sfacg.com/`，完整图片地址的查询参数会保留；页数以网站返回的图片数组为准。
