# 适配思路来源

本页记录内置站点适配时参考的公开资料。它们用于理解页面行为与选择测试方向，不代表将其代码、图片、账号数据或授权一并带入本项目。

## KakaoPage

- 用户提供的 `KakaoPage Downloader`（作者 ozler365）用于理解“仅观察阅读器已经返回给浏览器的数据”的实现方向。
- 作者公开脚本列表：[OZLER365 on Greasy Fork](https://greasyfork.org/en/users/1553223-ozler365)。

本项目独立实现了最小响应观察与队列交接，不包含原脚本的界面、PDF、自动跳转、购买或充值逻辑。

## RidiBooks

- [Ridibooks Comic Ripper](https://greasyfork.org/he/scripts/562807-ridibooks-comic-ripper)：用于确认阅读器 `generate` 响应可携带页面地址。
- [该脚本源码](https://greasyfork.org/he/scripts/562807-ridibooks-comic-ripper/code)：用于核对公开响应字段形态。

该脚本的发布页面与源码头部许可证声明不一致，因此本项目未复制其代码；RidiBooks 适配只读取浏览器在当前账号正常阅读时已经收到的 `data.pages`，不处理 DRM、Cookie、登录、购买、年龄验证或访问限制。
